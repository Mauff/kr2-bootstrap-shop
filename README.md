# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина, разработанную с использованием CSS-фреймворка Bootstrap.

## Используемый фреймворк

Bootstrap (подключен через CDN).

## Реализованные компоненты

- `navbar` (адаптивная навигация);
- `card` (карточки товаров);
- `btn` (кнопки);
- `badge` (значки статусов);
- `alert` (информационные сообщения);
- `modal` (всплывающее окно заявки);
- `form-control`, `form-select`, `input-group`, `form-check` (элементы формы);
- `accordion` (раскрывающийся блок вопросов).

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница подробностей товара;
- `order.html` — страница с формой заявки;
- `css/custom.css` — файл с минимальными кастомными стилями;
- `README.md` — описание проекта.
